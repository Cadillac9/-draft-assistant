Draft Assistant v9 — Live Sleeper Data

Upload BOTH files to the root of your GitHub Pages repo:
- index.html
- service-worker.js

What v9 does:
- Refreshes Sleeper season projections for QB/RB/WR/TE/K.
- Refreshes current team, status and injury information.
- Caches live data on the iPhone for 12 hours.
- Adds a "↻ Live Data" button for a manual refresh.
- Falls back to the built-in Top 200/offline data if Sleeper cannot be reached.
- DST remains on the app's existing data until a later update.

No API key is required.
