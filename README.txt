LIVE DRAFT ASSISTANT - INSTALL NOTES

This folder is a standalone web app. It remembers your draft in the browser and can work offline after the first successful load.

IMPORTANT FOR IPHONE:
You cannot get the full "Add to Home Screen" app experience by simply opening the HTML file from Files. The app needs to be hosted on an HTTPS website first.

EASIEST ROUTE:
1. Upload the contents of this folder to a simple static-site host such as Netlify, GitHub Pages, or Cloudflare Pages.
2. Open the hosted website in Safari on your iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Name it Draft Assistant and tap Add.

After that it will launch from your Home Screen in an app-like standalone window.

The app stores picks, notes, settings, and custom players locally on that device.
